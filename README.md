# قصّتي — Qassati

استوديو لتجربة قصّات الشعر واللحى بالكاميرا مباشرة على وجهك قبل زيارة الحلاق.

- **44 قصة شعر** (قصير، كلاسيكي، عصري، متوسط وطويل، مجعّد وأفرو) و**19 لحية وشارب**.
- **10 ألوان شعر**، وتحكم كامل بالحجم والعرض والارتفاع والميلان والشفافية، بالسحب والتكبير بإصبعين.
- **دليل كامل لكل قصة**: أشكال الوجه المناسبة، ونوع الشعر، ومستوى العناية، والأطوال وأرقام الماكينة، وجملة جاهزة تقولها للحلاق، والمنتجات، ونصائح.
- **اختبار شكل الوجه** بثلاثة أسئلة، مع ترشيحات تناسب وجهك.
- **تصوير وحفظ ومقارنة** الصور جنباً إلى جنب (تُحفظ على جهازك فقط).

## بدون ذكاء اصطناعي

كل القصّات تُرسم بالكود (SVG) عبر محرك هندسي في `lib/hairEngine.js`، دون صور جاهزة ودون أي نموذج ذكاء اصطناعي.
أنت تضع وجهك داخل الإطار الذهبي وتضبط القصة بيدك. لا يُرفع أي شيء إلى أي خادم.

## التشغيل

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

> الكاميرا تحتاج اتصالاً آمناً (https) أو `localhost`. وعند النشر على Vercel تعمل مباشرة.

## البنية

| الملف | الوظيفة |
|---|---|
| `lib/hairEngine.js` | محرك رسم الشعر واللحى (هندسة + ملمس) |
| `lib/catalog.js` | بيانات القصات واللحى وتفاصيلها |
| `components/Studio.jsx` | الكاميرا والإيماءات والتصوير |
| `components/Catalog.jsx` · `DetailSheet.jsx` | الكتالوج وصفحة التفاصيل |
| `components/FaceQuiz.jsx` | اختبار شكل الوجه |
| `components/Gallery.jsx` | المعرض والمقارنة |
